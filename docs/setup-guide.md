# FACEIT SG 用トンネル 導入手順（Windows）

所要時間 5 分。管理者権限が必要。

## 1. 受け取ったフォルダを置く
配布されたフォルダ（`start-tunnel.bat`、`start-tunnel.ps1`、`〇〇-split.conf` の 3 ファイル）を
デスクトップなど好きな場所にそのまま置く。**`.conf` には秘密鍵が入っているので他人に渡さない・グループに貼らない。**

## 2. `start-tunnel.bat` をダブルクリック
「このアプリがデバイスに変更を加えることを許可しますか」→ はい。あとは自動で
- WireGuard が無ければインストール
- トンネルを開始して経路を測定（回線側の経路に当たり外れがあるので、外れなら自動で引き直す）
- 当たりが出たらその設定を保存して「OK」と表示

「OK」が出れば完了。Enter で閉じる。

## 3. 次回以降・宛先が増えたとき
WireGuard アプリ（スタートメニューにある）で `〇〇-split` を「有効化」するだけ。配布者から「リストを更新した」と連絡があったら、もう一度 `start-tunnel.bat` を実行すれば最新の宛先が自動で取り込まれる。
もし調子が悪くなったら、もう一度 `start-tunnel.bat` を実行すれば引き直す。

## 動作確認したい時
コマンドプロンプトで `ping 10.66.0.1`。平均 80〜100 ms なら正常。150 ms 以上なら `start-tunnel.bat` を再実行。

## 補足
- このトンネルはシンガポールのゲームサーバー宛の通信だけを通す。Discord・ブラウザ・Steam ダウンロードには影響しないのでつけっぱなしで OK。
- ゲーム中に ping が改善しない → 試合中に CS2 コンソールで `status` と打ち、`udp/ip` の行の IP を配布者に送る（対象サーバーの追加に使う）。
- NordVPN など他の VPN が入っていても共存できる（確認済み）。
